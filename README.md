# 📊 Maven Fuzzy Factory Sales Analysis

## 📌 Project Overview

This project demonstrates an end-to-end sales analysis using SQL, Microsoft Excel, and Tableau.

The objective was to analyze sales performance, product performance, refunds, and monthly trends while building interactive dashboards for business decision-making.

---

## 🛠️ Tools Used

- SQL (MySQL)
- Microsoft Excel
- Tableau
- GitHub

---

## 📂 Dataset

The Maven Fuzzy Factory dataset contains:

- Orders
- Order Items
- Products
- Refunds
- Website Sessions
- Website Pageviews
